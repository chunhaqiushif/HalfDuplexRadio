MOD修改了“语音激活”、“按键通话”的机制：
不使用无线电时，默认以本地语音进行通话

同一无线电频道同一时刻只允许一个人说话
别人正在这个频道说话时，你按住无线电键发出的语音会提示占线

新增了紧急通话
所有人都会接受到通话，并且无视占线情况
用于发生意外时的紧急无线电通话或是指挥频道

只有无线电语音会遵循这个规则，文字聊天不受影响

HalfDuplexRadio (C#)

Developed with AI assistance; editing, review and debugging are handled by me. Please do not use this mod if that bothers you.
The code and content have been reorganized around the official plugin system (IBarotraumaPlugin). It no longer depends on Lua For Barotrauma; the compiled ".dll" is loaded directly by the game's native plugin loader.

Please note: using .dll files in a mod carries risks, and the game warns about this in its own UI.
To review the code externally, visit GitHub: https://github.com/chunhaqiushif/ProtagonistNeverDie
To review it in-game, expand the mod at the prompt and click the decompile option to view the code.
