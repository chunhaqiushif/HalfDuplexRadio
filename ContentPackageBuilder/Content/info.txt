HalfDuplexRadio (C#)

Developed with AI assistance; editing, review and debugging are handled by me. Please do not use this mod if that bothers you.
The code and content have been reorganized around the official plugin system (IBarotraumaPlugin). It no longer depends on Lua For Barotrauma; the compiled ".dll" is loaded directly by the game's native plugin loader.

Please note: using .dll files in a mod carries risks, and the game warns about this in its own UI.
To review the code externally, visit GitHub: https://github.com/chunhaqiushif/HalfDuplexRadio
To review it in-game, expand the mod at the prompt and click the decompile option to view the code.

Features:
The mod modifies the mechanics of "voice activation" and "push-to-talk":

When not using the radio, voice communication defaults to local voice.
Only one person is allowed to speak on the same radio channel at a time. When someone else is speaking on that channel, holding the radio key to transmit will notify you that the line is busy.

Emergency Call:
The call reaches everyone and ignores the busy-line condition (used for emergency radio calls in case of accidents or for the command channel).
The default key is "P", which can be changed in the settings.

Only radio voice follows these rules; text chat is unaffected.

The mod is currently undergoing testing; please let me know if you encounter any issues.
